# Project: Armenian NLP toolkit

## Summary
An NLP toolkit for Armenian, a low-resource language. The README includes a results table and an explicit limitations section.

## Why
Armenian has limited labeled data and few off-the-shelf tools, so the project documents what works, what does not, and where the data gaps are.
