# Project: Foody

## Summary
Foody is a recipe and pantry app. It recommends recipes based on what is in your pantry and supports favourites, drafts, and search history.

## Stack
- Back-end: Nest.js, Drizzle ORM, PostgreSQL, Clerk authentication, Cloudinary uploads.
- Front-end: Next.js.
